# Car Quiz App 

A mobile quiz app built with React Native and Expo where users test their knowledge by identifying car models from pictures.

# Features Highlight

Reusable Component (CarQuestion): Groups the question text, image, and dropdown picker together so the code doesn't repeat for each question.

Smooth Scrolling (ScrollView): Allows users to scroll up and down easily when the content goes past the screen height.

Custom Header: Uses Flexbox and icons to center the title neatly at the top of the app.

Scoring Logic: Tracks the user's selected answers using state hooks and checks them against the correct car models to calculate the final score.

Feedback Alert: Displays a formatted pop-up message showing the user's score upon submission.
